Automation workflow

User-created alerts drive the background monitor. The app keeps the exchange source and delivery history for every notification.
1. AlertUser selects a company and exchange.
2. DetectBackground worker checks new financial filings.
3. ExtractStructured filing/iXBRL values are parsed.
4. CalculateQoQ and YoY are computed deterministically.
5. FormatReference-style report image plus summary.
6. NotifyWhatsApp receives text and image.
NSE: the monitor uses the live NSE Integrated Filing - Financials path and follows the exchange Details/XBRL source. BSE: filing-level alerts are supported from the configured company result page; numeric extraction is only performed when a structured source is available.
